# Studio 워크플로우 규칙표

채점은 Studio 워크플로우 결과로 한다. `judge/`의 규칙을 Studio로 옮길 때 이 표를 본다. 노드 이름과 코드 노드 지원 여부는 Studio 화면에서 확인한다.

## 처리 순서

| 순서 | 할 일 | 나오는 값 |
| --- | --- | --- |
| 1 | 문서 파싱, 서류 종류 분류 | 서류 목록. 애매하면 `UNKNOWN_DOC` |
| 2 | 경로 A: 파싱한 표에서 값 찾기 | 필드 값, 위치 |
| 3 | 경로 B: 원본을 따로 읽어 값 뽑기 | 필드 값, 인용 |
| 4 | 값 확정: 두 값 비교 후 검산 | 확정 값 또는 이유 코드 |
| 5 | 서류 간 비교 | 불일치 목록 |
| 6 | 누락, 중복 검사 | 누락·중복 목록 |
| 7 | 결론 | 판정 값 |

## 값 확정

| 경우 | 결과 |
| --- | --- |
| 두 값이 같고 검산 통과 | 확정 |
| 두 값이 같은데 검산 실패 | 검토 필요 (`INTERNAL_MISMATCH`) |
| 두 값이 다르고 하나만 검산 통과 | 통과한 값으로 확정 |
| 둘 다 통과 | 검토 필요 (`AMBIGUOUS_VALUE`) |
| 둘 다 실패 | 검토 필요 (`READ_CONFLICT`) |
| 다른 항도 흔들려 검산 불가 | 검토 필요 (`UNSTABLE_BASE`) |
| 이름, 날짜처럼 검산식이 없는 값 | 같으면 확정, 다르면 `READ_CONFLICT` |

## 검산식

| 서식 | 식 |
| --- | --- |
| 진료비 영수증 | 총액 = 본인부담금 + 공단부담금 + 전액본인부담 + 비급여 |
| | 환자부담 = 본인부담금 − 상한액 초과금 + 전액본인부담 + 비급여 |
| | 공단부담 총액 = 공단부담금 + 상한액 초과금 |
| | 납부할 금액 = 환자부담 − 이미 낸 금액. 10원·100원 단위로 끝수를 버린 값도 정상 |
| | 납부한 합계 = 카드 + 현금영수증 + 현금 |
| 약제비·간이 영수증 | 총액 = 네 칸의 합, 환자부담 = 총액 − 공단부담금 |

## 서류 비교

확정된 값끼리만 비교한다. 확정되지 않은 값이 끼면 불일치로 판정하지 않고 검토 필요로 넘긴다.

| 비교 | 불일치 조건 |
| --- | --- |
| 세부내역서 합계 ↔ 영수증 네 칸과 총액 | 금액이 다름 (끝수 조정을 반영한 합계로 비교) |
| 환자 이름 | 모든 서류 쌍에서 가린 글자 빼고 다름 |
| 진료일 | 영수증 기간 밖의 날짜 있음 |
| 요양기관 | 다름 |
| 약국 조제일 | 어느 처방전의 사용기간에도 들지 않음. 발급일이 첫날 |
| 여러 날 내역서 ↔ 그날 영수증 | 금액이 다름. 영수증이 없는 날은 검토 필요 |

## 누락과 중복

금액 등 조건 값이 확정되지 않았으면 누락으로 판정하지 않는다. 증빙은 진단명이 있어야 인정한다.

| 규칙 | 조건 | 결과 |
| --- | --- | --- |
| D1 | 영수증 없음 | 누락 |
| D2 | 통원 3만 원 초과, 질병분류기호 처방전도 증빙도 없음 | 누락 |
| D3 | 통원 10만 원 초과, 증빙 없음 | 검토 필요 |
| D4 | 산부인과, 항문외과, 비뇨기과(비뇨의학과), 피부과 통원, 증빙 없음 | 검토 필요 |
| D5 | 입원: 진료비 계산서, 세부내역서, 진단서 중 빠짐. 50만 원 이하는 확인서로 대체 가능 | 누락 |
| 중복 | 요양기관과 영수증 번호가 같음. 번호가 없으면 기관, 기간, 환자, 납부 금액이 같음 | 중복 |

금액 기준은 중복을 뺀 영수증의 환자부담 합계로 본다.

## 결론

| 판정 값 | 조건 |
| --- | --- |
| 심사 진행 | 이슈 없음 |
| 보완 요청 | 불일치, 누락, 중복만 있음 |
| 검토 필요 | 읽기 오류나 기타 검토 필요가 하나라도 있음 (보완 요청보다 우선) |

## 먼저 확인할 것

- 코드 노드가 있으면 검산, 비교, 결론을 코드로 옮긴다. 판정이 매번 같아야 하기 때문이다.
- 코드 노드가 없으면 LLM 노드로 판정하게 되므로 규칙을 줄이고, 같은 입력을 여러 번 돌려 결과가 같은지 시험한다.
- 출력 키를 먼저 정하고 정답지, 설계서와 똑같이 맞춘다. 키 이름이 다르면 실행 정확도가 0점이다.
