# 할 일: 제출본에 blank 클래스 넣기 (설정 #10)

혁진이 맡기는 일이다. 이번에는 **제출본 워크플로를 직접 수정**한다. 끝나면 혁진에게 보고하고, 그 전에는 다른 사람이 제출본을 고치지 않는다.

- 제출본: `컴학감동_미션2_실손보험 청구 서류 검증` (컴학감동 프로젝트), 현재 최신 **설정 #9**
- 근거: 복사본 `(시험용 이슈)` 설정 #3에서 blank 클래스로 빈 페이지 문제가 해결됨 (`ISSUES_1107_결과.md` 2번)
- 가상 문서만 쓴다

## 1. 설정 #10 만들기

1. Chrome 창을 충분히 넓힌다. 좁으면 모바일 화면이 나와 편집기와 실행 버튼이 없다.
2. 제출본을 열고 설정 번호가 **#9(최신)** 이고 `초안` 표시가 없는지 확인한다. 다르면 멈추고 혁진에게 묻는다.
3. 상단 반짝이(✦) 버튼 → 워크플로우 편집기 → `청구서류-분류`(Classify) 노드를 누른다.
4. 클래스를 하나 추가한다.
   - 이름: `blank`
   - 설명: `글자가 없거나 거의 없는 빈 페이지`
   - **어떤 노드에도 연결하지 않는다.**
5. 다른 설정(프롬프트, 연결, 분할 방식 `PAGE`)은 건드리지 않는다.
6. 편집기를 닫고, 설정 번호 메뉴에서 `설정 #10 초안`의 **저장**을 누른다. 변경 내역에 분류 변경만 있는지 본다.

## 2. 시험 파일 올리기

- `시험_이슈_영수증_빈페이지.pdf` (set01 영수증 + 빈 페이지)를 제출본에 업로드한다. 복사본에서 쓴 파일과 같은 것이다.
- 파일 이름은 `시험_`으로 시작해야 한다. 최종 게시 때 샘플에서 뺀다.

## 3. 실행 (2회)

- 설정 #10으로 **파일 19개 전체**(기존 18개 + 빈 페이지 1개)를 선택해 실행한다. 확인 창에서 `#10`과 `19개`를 확인한다.
- 2번 돌린다.
