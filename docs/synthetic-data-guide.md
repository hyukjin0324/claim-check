# 가상 서류 제작 가이드

① 데이터·정답지 담당용. 실제 서류 수집 기준은 [조사 메모](research-notes.md) §5를 본다.

## 준비물

| 자료 | 위치 |
| --- | --- |
| 공식 서식 | `forms/` |
| 케이스 목록 | [case-plan.md](case-plan.md) |
| 케이스별 값 (정답지 초안) | `answers/case_NN.json` |
| 칸 번호와 검산식 | [기능명세서](functional-spec.md) §3 |

## 제작 순서

1. `answers/case_NN.json`에서 서류 목록과 값을 확인한다.
2. `forms/`에서 `form_no`에 맞는 서식을 고른다.
3. 값을 서식에 채운다. 처음 한 건은 손으로, 많아지면 PDF 위에 글자를 얹는 스크립트로 만든다.
4. 합계 칸까지 다 채운 뒤 아래 "값 확인"을 한다.
5. `capture`에 적힌 상태로 파일을 만든다.
6. `cases/case_NN/`에 넣고, 파일 이름을 정답지의 `file_name`과 맞춘다.
7. 다른 팀원이 서류와 정답지를 대조한다.
8. 대조가 끝나면 정답지의 `"draft": true`를 지운다.

통원확인서, 입퇴원확인서, 진료확인서, 카드 전표는 공통 서식을 찾지 못했다. 아래 항목으로 단순하게 만든다.

| 서류 | 넣을 항목 |
| --- | --- |
| 확인서 | 제목, 환자 성명, 진단명, 통원일 또는 입원·퇴원일, 요양기관명, 발행일 |
| 카드 전표 | 가맹점명, 사업자번호, 거래일시, 카드번호 일부, 승인번호, 결제 금액. 급여·비급여 구분은 넣지 않는다 |

처방전과 진단서의 주민등록번호, 면허번호, 전화번호도 가상 값으로 넣는다. 처방전의 질병분류기호는 환자가 요구하면 비어 있을 수 있으니, 비어 있으면 D2 기준을 채우지 못한 것으로 본다.

## 값 넣는 규칙

- 정답지의 키와 서식 칸을 맞춘다. **칸 번호는 서식마다 다르다.**
- 진료비 영수증의 `copay_total`은 ①, `insurer_total`은 ②, `full_copay_total`은 ③, `noncovered_total`은 ④, `cap_excess`는 ⑤다.
- 약제비·간이 영수증의 `bill_total`은 ⑤, `patient_total`은 ⑥이다.
- 납입 확인서의 ①은 공단부담금, ②는 본인부담금이다.
- 환자, 병원, 번호, 코드, 진단은 모두 가상 값을 그대로 쓴다. 실제 사람이나 병원 이름으로 바꾸지 않는다.
- 공개 캡처의 값을 그대로 옮기지 않는다.
- 값을 바꿨다면 정답지와 `scripts/generate_case_drafts.py`도 같이 고친다.

## 값 확인

```bash
python3 scripts/generate_case_drafts.py
```

`통과`가 나오면 금액 검산식과 필요 서류 규칙이 정답지와 맞는다는 뜻이다. **OCR이나 서류 이미지를 검사하는 것은 아니다.** 서류에 옮긴 값은 사람이 대조한다.

## 파일 만드는 법

| capture | 만드는 법 |
| --- | --- |
| 깨끗한 이미지 | 200dpi 이상 PNG로 저장 |
| 손글씨로 채운 뒤 스캔 | 출력해 손으로 적고 스캔 |
| 칸을 연하게 인쇄한 뒤 촬영 | 해당 값의 글자색만 연한 회색으로 바꿔 출력 후 촬영 |
| 구긴 뒤 펴서 촬영 | 출력본을 구겼다 펴서 촬영. 금액이 사람 눈에는 읽혀야 함 |
| 15도 기울여 촬영 | 표 전체가 나오게 기울여 촬영 |
| 그림자가 지게 촬영 | 금액 칸에 손이나 물건 그림자를 드리움 |
| 잘라 촬영 | 정답지에 적힌 부분이 안 나오게 촬영 |

- 글자 정보가 남은 PDF를 그대로 넣지 않는다. 그러면 OCR 시험이 되지 않는다.
- 사람도 못 읽을 만큼 망가졌다면 다시 찍거나, 정답지를 `needs_review`로 바꾼다.
- 사진의 위치 정보(EXIF)를 지운다.

## 초안의 한계

- 금액은 규칙에 맞춘 가상 값이다. 실제 진료비 수준과 다를 수 있다.
- 저품질 케이스의 결론은 실제로 만든 파일을 보고 다시 확인한다.
- 정답지 형식은 `schema/`가 확정되면 맞춘다.
- 실제 서류 묶음이 모이면 비슷한 가상 케이스를 대체한다.
